# 奇幻怪獸拼貼樂園 - 創意手作與著色 (Halloween 2026)

剪紙立體怪物 × 自由著色 × 觸控手寫簽名

設計：陳佳釧老師  
免登入即可創作！

## 功能特色

1. **怪獸形體**：白色幽靈怪、橘色南瓜怪、胖胖橢圓豆豆怪、三叉狂野角怪、流蘇水母怪、圓角方塊怪、梨形泡泡怪、淘氣波浪怪。
2. **五官與配件**：多款大眼睛、逗趣大嘴、手腳長肢與萬聖節配件。
3. **觸控繪圖**：自由筆刷手寫塗鴉、顏色選取、粗細調整、橡皮擦與復原重做。
4. **名牌產生器**：輸入姓名即可一鍵在作品蓋上專屬名字印章。
5. **相片匯出**：一鍵將作品匯出保存為高畫質 PNG 照片。

## 部署說明

- **Netlify**: 直接連接本倉庫，發布目錄設為 `.` 即可。
- **GitHub Pages**: 在倉庫 Settings -> Pages 啟用 main 分支即可瀏覽。
